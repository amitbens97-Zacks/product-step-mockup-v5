# מוק-אפ v5: שלב "בניית סל מוצרים" (לפי מערכת העיצוב)

מוק-אפ של **ממשק בלבד** לשלב 4 מתוך 21, הראשון בפרק 2 "שביל הכסף". זו גרסה v3 אחרי החלת מערכת העיצוב של FlowBiz: צבעי הדגל, מחברת, עיפרון צבעוני, וכל כללי חוויית המשתמש, הכתיבה והמשחוק.

- **גרסה חיה:** https://product-step-mockup-v5.vercel.app
- **מערכת העיצוב:** https://claude.ai/artifact/NAtZk1fxcAdpP8UGDa8X4C. הטוקנים והרכיבים שלה נמצאים ב-`assets/ds`.
- **אין צד שרת:** כל הנתונים נשמרים בזיכרון הדפדפן, ותגובות ה-AI הן טקסטים קבועים מראש (`src/data.js`). העסק לדוגמה: יועץ שיווק דיגיטלי לעסקים קטנים.
- **דרישות האפיון:** כפתור הקוד בשורה העליונה (או Shift+D) פותח את ההערות למפתחים.

## הרצה

אתר סטטי, בלי תהליך בנייה ובלי התקנות. צריך רק שרת קבצים:

```bash
python -m http.server 4178
```

ואז לפתוח את http://localhost:4178.

## מה מהמסמך מיושם כאן

| כלל | איך זה נראה במוק-אפ |
|---|---|
| שלושה אזורים קבועים | שורה עליונה (שלב ופרק, התקדמות במרכז, "לדף הבית"), דף המחברת, שורה תחתונה ("חזרה", מצב אחד, כפתור ראשי אחד) |
| מסך אחד בלי גלילה | כל מסך נכנס ב-1280×720. רשימות ארוכות נגללות בתוך החלונית שלהן |
| מסך פתיחה לכל שלב | מסך מלא (לא חלון קופץ), רק בכניסה הראשונה. סדר קריאה אחד: הכותרת, האיור, הכפתור "מתחילים". חלקי השלב, הזמן, התוצר ו"יש לי כבר סל מוצרים" בגוש שקט אחד. `?from=home` (כמו "המשך מכאן") מדלג עליו, ובהערות למפתחים אפשר להציג אותו שוב |
| שאלה ראשונה נקייה | כותרת וארבעה כרטיסים, בלי פתקים, בלי חלונית ריקה ובלי תיבות אישור. "המשך" מאשר הכל |
| סיכום סביב התוצר | המשפך גדול במרכז, לחיצה על שכבה פותחת את המוצרים שלה לעריכה. בצד רק שורת המחץ והערת השותף. `?scenario=full` נכנס ישר לסיכום |
| לא שואלים פעמיים | הנתונים מהשלבים הקודמים מסומנים "מילאנו לפי..." |
| אנטר ממשיך | ↵ על הכפתור הראשי |
| שמירה אוטומטית | "שומר..." ואז "נשמר" באמצע השורה התחתונה |
| ביטול אחיד | "ביטול" ל-5 שניות אחרי כל פעולה אוטומטית (מילוי של השותף) |
| כפתור מושבת מסביר | "צריך לפחות מוצר אחד כדי להמשיך" |
| השותף | בועה עם התמונה של עידו, נגררת לכל מקום פנוי, לא נוחתת על כפתורים. "להכניס לתשובה" ממלא את השדה. אחרי דקה בלי פעולה הוא מציע דוגמה |
| החלונית בצד | "סל המוצרים שלך · מתמלא עם כל תשובה". ברוחב 1024 עד 1279 היא כפתור בשורה התחתונה, ובטלפון לשונית |
| מסך הסיום | פתק התג, "+800 ₪" בירוק עם קו עיפרון, התקדמות הפרק, "חסכת עד עכשיו", קונפטי מחברת לשנייה, "לשלב הבא" |
| טיפוגרפיה | Rubik לכותרות ולמספרים, Assistant לכל השאר, Amatic SC לכתב יד. רק הגדלים 12, 14, 16, 18, 24, 36 (ו-26 לכתב יד, 48 לסכום הניצחון) |
| צבע | כחול הדגל רק למה שלוחצים עליו. ירוק רק לכסף שנחסך. אדום רק לשגיאה |
| כתיבה | "אנחנו" למה שעושים יחד, "שלך" למה ששייך ליזם, בלי לוכסן, בלי אימוג'י, כפתורים ממילון הכפתורים |

## מבנה הקבצים

```
index.html              גופנים, טוקני Tailwind לפי ערכת הדגל, מרקמי עיפרון
assets/ds/              טוקנים, רכיבי fb-* ועזרי עיפרון ממערכת העיצוב
assets/partners/        התמונות של עידו, מאיה וביזי
src/main.js             מעטפת השלב: שורות קבועות, כותרות, החלונית בצד, השותף, ניווט ושמירה
src/components.js       רכיבים משותפים: כפתורים, שורות קבועות, פתקים, השותף
src/screens/            מה ידוע, סל המוצרים, תמחור, סיכום וסיום
src/funnel.js           המשפך הדינמי
src/data.js             נתוני דוגמה, הצעות AI מדומות, תרחישי בדיקה, נתוני השלב
src/devnotes.js         ההערות למפתחים
```

## תצוגת מחשב ומובייל

במחשב, "מובייל" מציג את המוק-אפ בתוך מסגרת טלפון (390×844). בטלפון, "מחשב" מרחיב את העמוד ל-1280. ההתקדמות עוברת בין התצוגות.
